Detailed Description

Procedural sound synthesis for the match audio. Every sound is built from noise, oscillators and filters at run time: there are no sample files.

Nothing here allocates or locks, so it is safe on the audio thread. The noise generators are private xorshift states, independent of the game's seeded RNG, so audio can never influence a simulation.
