Detailed Description

Short welcome tour of a new career: the club, what the board expects, the next thing to do and how Continue works.

It opens once when a career is started from the club choice (and again on request from the Help screen), so nothing about it is stored in a save. Every page can be skipped; the texts come from the career's real state, read once when the tour opens.
