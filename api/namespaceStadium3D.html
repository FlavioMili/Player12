Detailed Description

Static world-space geometry of the 3D match view: ground, markings, goals, corner flags, advertising boards, stands with crowd, and floodlights.

Everything is built once per match (the crowd needs the kit colours) and only re-projected per frame by MatchRenderer3D. No RNG is involved: all variation comes from a fixed integer hash so the stadium is identical on every frame and every run.
