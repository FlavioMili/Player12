Detailed Description

The match sandbox's record of one match (debugger phase 1, the "Tier A" log): what the planner, the players and the referee decided and what came of it, in tick order. Only changes are kept: a player holding the same intent for a minute is one entry.

Hooks may run on the quick-result worker, so every access goes through the recorder's lock (see lock()).
