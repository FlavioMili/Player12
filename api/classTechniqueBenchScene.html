Detailed Description

Technique bench (Notes and plans/match_engine_technique_bench_plan.md §6): the catalogue of pass and shot tests with tag filters, run with the sandbox's tuning (the contact view edits it), results as success curves against skill or a grid, each run kept to compare with the next; one test's detail and Watch.
