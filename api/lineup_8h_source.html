293/***************************************************************
294 * This is how to visualise the grid where to place the players:
295 *
296 * GK: (always separate, fixed role)
297 *
298 * Row 0 → furthest forward (attacking line)
299 * Row 4 → deepest outfield line (defensive line)
300 *
301 * Example 5×5 grid (row × col):
302 *
303 * (0,0) (0,1) (0,2) (0,3) (0,4)
304 * (1,0) (1,1) (1,2) (1,3) (1,4)
305 * (2,0) (2,1) (2,2) (2,3) (2,4)
306 * (3,0) (3,1) (3,2) (3,3) (3,4)
307 * (4,0) (4,1) (4,2) (4,3) (4,4)
308 *
309 * To place a player in a position, use:
310 * index = row * LINEUP_GRID_COLS + col;
311 *
312 * Example: Striker at (0,2) → index = 0 * 5 + 2 = 2
313 * Left-back at (4,0) → index = 4 * 5 + 0 = 20
314 *
315 ***************************************************************/
