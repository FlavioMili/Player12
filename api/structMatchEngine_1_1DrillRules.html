Detailed Description

Rule switches for drills; the defaults are the Laws of the Game.

Member Data Documentation

◆ chaseEffort

bool MatchEngine::DrillRules::chaseEffort = false

On: a player held on an urgent drill target runs as hard as one chasing a loose ball, whatever job his side's brain gave him, so a squad drill's runners all go equally hard (a lone runner gets that job anyway). Off: his brain's job sets his effort.

◆ layers

bool MatchEngine::DrillRules::layers = true

Off (the brain redesign's neutral ladder, plan section 3): nothing is layered on the players' decisions. The sliders are the base tactics (no score, underdog or shout effects), the managers make no touchline calls, both sides have full tactical familiarity and no execution edge (home, team talk, numbers), the brain skips its own game-state terms, and drill players hold no formation slot. Home advantage is set when the engine is built (the sandbox's drill run makes it 0).

◆ minimumPlayers

bool MatchEngine::DrillRules::minimumPlayers = true

Off: a side below seven players does not abandon the match.

◆ offside

bool MatchEngine::DrillRules::offside = true

Off: nobody is ever offside.

◆ periods

bool MatchEngine::DrillRules::periods = true

Off: the halves never end (no half time, its rest or full time), so a drill can run as long as it likes.
