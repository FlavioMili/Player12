Detailed Description

A session being run: the squad's players, and the current exercise's zones, each a drill run on the squad's own players.

picks: the players to train (the first of them make up the squad; reference players fill any gap). seed: the session's; each zone's drill runs on its own seed from it, so the session repeats. record: attach each zone's recorder. Throws std::invalid_argument, with checkSessionPlan's message, if the plan has a problem; so each exercise's zones are the plan's, one for one and in order.
