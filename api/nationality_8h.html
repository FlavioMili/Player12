Detailed Description

Nationalities of the running world.

The 159 built-in nationalities (the Language enum, table in languages.h) keep their numbers: saves store them as integers. A world can add peoples of its own; each takes a free 16-bit value after the built-in ones when the world is installed (World::install), in the order of its countries, so a career reloads the same numbers from the world stored in its save. Game code reads names through these functions, never the tables.
