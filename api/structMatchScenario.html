Detailed Description

A fully-specified, deterministic snapshot of players and ball that the match engine can load. Used by the headless scenario suite to exercise pass, shot, and carry decisions without organic full-match states. The renderer never sees this path; it only consumes the read-only MatchRenderSnapshot.
