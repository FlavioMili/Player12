Detailed Description

The managed club's tactics: style and instructions, player roles and duties, and the shape with the ball.

Every change applies to the club's tactic in memory straight away (it is written with the next save), so leaving the screen by any route never loses an edit; Revert restores the tactic as it was on arrival.
