◆ unit

std::string_view DerivedStatInfo::unit

Physical meaning, if any: the unit, the value at two anchor ratings (a straight line through them), and its safe range. The range holds the whole line from rating 0 to 1, so the clamp only catches a bad recipe or override and never flattens a real rating (the –check test enforces it). Empty unit: a rating only.
