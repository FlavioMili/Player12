Detailed Description

Crash-safe persistence of career saves.

A career is played on an in-memory working database; the slot file is only replaced by a complete, verified snapshot (online backup to <slot>.tmp, quick_check, fsync, rotate backups, atomic rename, fsync of the directory). An interrupted save therefore never damages the previous one. See src/database/migrations/README.md, "Save protocol".
