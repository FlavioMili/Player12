Detailed Description

A few neighbouring spectators (up to CLUMP_SEATS x CLUMP_ROWS) drawn as one quad when they are far away. The quad runs up the tier from the front row to the heads of the next clump's front row, so clumps tile the stand without gaps from any angle. Members are stored back row first so nearer rows overlap the ones behind them.
