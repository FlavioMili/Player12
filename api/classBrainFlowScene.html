Detailed Description

The brain flow visualiser (Notes and plans/ match_engine_brain_flow_tool_plan.md): the new brain framework as a flow, top to bottom (situation, reading, goal, options, measures, weights, judgement, pick, body), on a live example scored by Capybara's own code. The default flow has no influence layers; each layer can be switched on to see which parts of the flow it touches, and by how much.
