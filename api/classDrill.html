Settings widgets: presets, then parameters as sliders or choices. Two columns place labels above controls and retain section headers. includeSeed adds seed entry; stackedLabels also puts the situation picker and single-column labels above controls. Other views retain their default layout (ctrl+click a slider to type a value beyond its range).
