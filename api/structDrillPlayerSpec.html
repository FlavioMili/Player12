Detailed Description

Drills: minigames that isolate one behaviour of the match engine (see Notes and plans/match_engine_drills_plan.md). A drill is an ordinary engine run with drill rules, only its own players on the pitch and a script that steers it after every step, so the debugger tools work on it unchanged. One player a drill needs.
