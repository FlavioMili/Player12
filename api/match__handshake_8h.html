◆ HandshakeId

enum class HandshakeId : std::uint8_t
strong

The match's "handshake": how everything the game passes in (lineups, players' stats, strategies, formations, match context, condition, familiarity, team talks) becomes the match engine's own state - the attribute scale (level shift, stretch), the physical limits (top speed, acceleration, braking), slot roles, base positions, referee strictness. It runs at kickoff and whenever an input arrives later (a substitute, a tactics or formation change).

AARDVARK is the inherited conversion, kept frozen for comparison; the BINTURONG and later handshakes are the ones being developed. One handshake per match, chosen when the engine is built (the MatchEngine constructor), since the conversion starts there and works from both teams together.
