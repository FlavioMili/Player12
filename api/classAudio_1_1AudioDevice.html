Detailed Description

Plays a Mixer on the default output through an SDL audio stream (48 kHz stereo float). SDL pulls audio from its own thread through the stream callback, which renders straight from the mixer. Without an audio device (or with SDL_AUDIODRIVER=dummy) everything still works; nothing is heard. The mixer must outlive the device.

The audio subsystem starts on the constructing (main) thread, as SDL asks; the stream itself opens on a short-lived helper thread because connecting to the sound server can take tens of milliseconds.
