Detailed Description

Rebuilds a recorded match at any tick (debugger phase 2): a copy of the nearest saved state before it, continued with the match's logs and simulated forward. Every rebuilt tick is checked against the fingerprint recorded when the match was played, so a rebuild that does not reproduce the match is reported instead of silently shown.
