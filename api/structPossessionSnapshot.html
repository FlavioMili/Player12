Detailed Description

Value-only projection: safe to retain across steps and engine copies. IDs are historical identities, not pitch slots. No observer owns a second writable simulation state. Missing physical/deliberate-contact history is left unknown: lastPossessor/kicker cannot reliably reconstruct those facts.
