Detailed Description

The kit laid out on an engine's pitch: cones, lines and marked areas (training ground plan sections 4 and 5.2). Each has a name so a drill's rules can refer to it. The engine holds them and the views draw them; cones, lines and areas are drawn only; dummies are solid (T5).

Points are metres on the engine's pitch. Colours are packed as ImGui's IM_COL32 (0xAABBGGRR), so the views pass them straight through.
