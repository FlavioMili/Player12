Detailed Description

Chronological list of messages with read tracking.

The inbox keeps the newest MAX_MESSAGES messages; older ones are dropped. Only news that needs the manager's attention arrives unread: routine round-ups (transfer news, instalments) are filed as read, and repeated offers of the same kind (bids and loan offers for the club's players) are grouped into a weekly digest with a single unread message.
