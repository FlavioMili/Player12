◆ BrainId

enum class BrainId : std::uint8_t
strong

A side's "brain": the code that decides what its players do (where to go, how hard to run, what to do with the ball, set pieces, keeper positioning). The body (physics, execution, contests, rules) is shared by every brain.

AARDVARK is the inherited decision-making and BINTURONG its first rework, both kept frozen for comparison; CAPYBARA (generation C, the brain redesign) is the one being developed. Each side of a match picks one before kickoff (MatchEngine::setBrain), so two brains can play each other.
