Detailed Description

Weighting for the carrier decision (DecisionFrame; brain redesign plan section 15, step A): how much each of its measures counts for him. The defaults are MatchTuning's; the layers (team instructions, his role, a shout) move them. Weights that depend on the receiver (his role, an order on him) are set where the pass is scored.
