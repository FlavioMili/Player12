Detailed Description

Controller state for the externally controlled player, e.g. a human's pad in play mode. Directions are in pitch metres (x along the length toward x=105, y across toward y=68); only the direction and a magnitude up to 1 matter.

Shots and passes go through the same execution model as the AI's (the player's technique, pressure, distance and fatigue decide the error), so the stick only chooses where the player tries to play the ball. Movement jitter of one side's outfield players in open play, observed only (it changes nothing in the match): how the plan's targets and intents change from one refresh to the next, and how the runs follow. Not observed while tracking is off (background fidelity).
