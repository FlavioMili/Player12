Detailed Description

The size of the pitch one engine plays on, and the values built from it. Each MatchEngine holds its own; a match's is 105 x 68 m (MatchTuning::Pitch::MATCH_LENGTH_METRES / MATCH_WIDTH_METRES).

Positions are in metres from the top left corner (x along the length, y across the width); the ball's height is in metres; velocities and _METRES tuning are metres.
