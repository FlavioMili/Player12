Detailed Description

A keeper's dive (goalkeeper plan step 3, agreed 2026-11-07 as a first pass): only for a shot on target whose line passes beyond his standing reach, aimed as his hands are (its real line plus the Reflexes miss). Marked placeholders are mine.
