Detailed Description

The decision frame (brain redesign plan, section 11 phase 2 and section 15): Goal -> Options -> Scoring -> Weighting -> Decision.

An option's score is a sum of terms. Each term is a measure (Scoring: what he reads, on its own scale) times a weight (Weighting: how much it counts, set by a layer: the default, an instruction, his role, a shout, the game state). The terms are the calculation itself, so the debugger's breakdown of a score is exact rather than reported beside it.

◆ STEP_RATIO

constexpr float DecisionFrame::STEP_RATIO = 1.1F
inlineconstexpr

Weight steps (brain redesign plan, 2026-11-12; section 15 step B5). A layer gives a weight a signed number of steps; the steps on a weight are summed, soft-capped once, and the weight is default x ratio^steps. So 0 steps is no change, +1 and -1 cancel, and a weight never changes sign. Our own estimates, not researched (agreed 2026-11-20): a step is 10%, a layer gives at most 3 (a shout 2), and the sum is capped near 6.
