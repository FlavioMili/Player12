Detailed Description

Cheap per-match recorder fed by the match engine: touch maps, completed passes between team-mates, progressive passes, pressures, expected assists and final-third touches over time. Players are the engine's stats indices (MatchEngine::getPlayerStats()). Storage is allocated on the first recorded event, so a disabled recorder (background fixtures) costs nothing.
