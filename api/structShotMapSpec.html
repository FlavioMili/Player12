Detailed Description

Shot map: the Shot drill measured over a grid of spots in the final third, many runs per spot. Per spot: conversion against the engine's own xG (the calibration heatmap) and, in choice mode, whether and from where the shooter chose to shoot. Built on DrillMeasure (sweep: distance from the goal line; by: off centre).
