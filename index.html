Linux, macOS & Windows setup ↗
git clone https://github.com/FlavioMili/FootballManagement.git
cd FootballManagement
cmake --preset release
cmake --build --preset release --parallel 4
./out/build/release/src/Player12

Linux quickstart after installing the prerequisites. macOS and Windows need their platform-specific setup.
